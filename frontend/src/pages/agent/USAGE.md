# ApeRAG Agent 页面

## 概述

这是一个基于MCP-Agent架构的ApeRAG智能对话助手页面，提供类似ChatGPT/Cursor的现代化聊天体验，采用紧凑设计和高信息密度界面。

## 访问地址

启动前端服务后，访问：`http://localhost:3001/web/agent`

⚠️ **注意**：ApeRAG项目的路由配置了 `basename="/web"`，所以需要在路径前加上 `/web` 前缀

## 功能特性

### 1. 智能对话
- 支持多轮对话
- 基于选择的collections进行知识检索
- 显示搜索来源和相关度分数

### 2. Collection管理
- 点击底部工具栏的 `@` 符号选择knowledge collections  
- 紧凑型下拉列表，参考Cursor的高信息密度设计
- 文档数量显示在collection名称右侧，节省空间
- 支持多选collections，选择即时生效无需确认
- 已选择的collections显示为紧凑标签，可以随时移除
- 内置搜索框快速过滤collections

### 3. 模型选择
- 支持多种LLM模型切换
- 显示模型提供商图标
- 当前支持：Claude-3.5-Sonnet, GPT-4, GPT-3.5-Turbo, GLM-4

### 4. Web搜索增强
- 位于底部工具栏左侧的Web搜索按钮（搜索图标）
- 点击切换Web搜索功能的开启/关闭状态
- 激活时按钮会变为绿色高亮状态
- 搜索结果会在回答中标注网络来源

### 布局特点
- **紧凑设计**：参考ChatGPT的简洁风格，640px最大宽度居中显示
- **分层结构**：输入区域和工具栏分离，层次清晰
- **高信息密度**：Collection下拉列表紧凑显示，文档数量在右侧

## 使用方法

### 基本对话
1. 在输入框中输入问题
2. 按Enter或点击Send发送
3. 等待AI回答

### 选择Collections
1. 点击底部工具栏的 `@` 按钮
2. 在弹出的紧凑型下拉菜单中选择collections
3. 可以在搜索框中输入关键词过滤collections  
4. 勾选/取消勾选需要的collections，选择即时生效
5. 已选择的collections会显示在输入框上方的标签区域

### 切换模型
1. 在底部工具栏右侧点击模型选择器
2. 从下拉菜单中选择合适的模型
3. 后续对话将使用新选择的模型

### 启用Web搜索
1. 点击底部工具栏左侧的搜索图标按钮
2. 按钮会变为绿色高亮表示已启用
3. 再次点击可以关闭Web搜索功能
4. 开启后AI回答会包含最新网络搜索信息
